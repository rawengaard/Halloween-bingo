# Halloween-bingo

Åpne index.html (eller GitHub Pages-lenken) og trykk «Start bingoen».

## GitHub Pages
1. Nytt repo på github.com (f.eks. halloween-bingo).
2. Last opp ALT: index.html, .nojekyll og hele images/-mappen (Add file → Upload files → Commit).
3. Settings → Pages → Deploy from a branch → main, / (root) → Save.
4. Siden åpnes på https://BRUKERNAVN.github.io/REPO/ etter ca. ett minutt.

## Bytte bilder
Erstatt images/01.png … 36.png (samme navn). Antall settes i DEFAULT_COUNT nederst i index.html.

## Tips
Mellomrom/Enter = Neste. Legg #anim=heksekjele bak adressen for å teste én animasjon.
